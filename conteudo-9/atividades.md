## Questões de estudo

1. O que é uma lista simplesmente encadeada e como ela é formada?
2. Quais informações cada nodo armazena em uma lista simplesmente encadeada?
3. Qual é o papel do primeiro nodo (head) em uma lista simplesmente encadeada?
4. Por que, em uma lista simplesmente encadeada, o acesso aos elementos acontece de forma sequencial?
5. Explique a principal diferença entre uma lista simplesmente encadeada e uma lista comum do Python.
6. O que significa dizer que os elementos de uma lista simplesmente encadeada não ocupam posições fixas?
7. Por que a ordem dos nodos é fundamental para o funcionamento correto de uma lista simplesmente encadeada?
8. Cite uma vantagem e uma desvantagem do uso de listas simplesmente encadeadas em relação a listas baseadas em vetor.
