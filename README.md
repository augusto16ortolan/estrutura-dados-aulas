# Estrutura de Dados com Python

<figure><img src=".gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

Este material foi organizado para apoiar uma trilha de aprendizagem que combina
fundamentos conceituais, implementação em Python e análise de desempenho.
Embora o projeto esteja dividido em conteúdos menores para facilitar a leitura e
o reaproveitamento do material, a sequência sugerida para as aulas é a
seguinte:

## Sequência sugerida das aulas

1. **Introdução à disciplina, otimização, abstração e revisão de Python**
   Conteúdos-base: introdução à disciplina, sintaxe, controle de fluxo,
   funções, estruturas nativas e modularização.
2. **Programação Orientada a Objetos em Python**
   Conteúdos-base: motivação da POO, conceitos, classes, objetos e métodos.
3. **Pilhas**
   Funcionamento, operações, aplicações e eficiência.
4. **Filas**
   Funcionamento, operações, aplicações e eficiência.
5. **Nodos e listas lineares**
   Base conceitual para listas encadeadas.
6. **Listas simplesmente encadeadas**
   Estrutura, operações e desempenho.
7. **Listas duplamente encadeadas**
   Estrutura, custo de memória e cenários de uso.
8. **Algoritmos de ordenação**
   Conceitos, comparação entre estratégias e análise de desempenho.
9. **Busca binária**
   Pré-requisitos, eficiência e aplicação prática.
10. **Árvores binárias**
    Estrutura, conceitos iniciais e percursos fundamentais.

## Como usar o material

Cada conteúdo foi pensado para funcionar em camadas:

* **Página principal** com a explicação conceitual do tema
* **Exercícios práticos** para implementação e experimentação em Python
* **Atividades** para discussão, revisão e fixação

Assim, você pode seguir a sequência sugerida das aulas sem perder a
granularidade do material escrito.
