## Questões de estudo

1. O que é uma fila e por que ela é considerada um Tipo Abstrato de Dados (TAD)?
2. Explique, com suas próprias palavras, o que significa a regra FIFO (First In, First Out) em uma fila.
3. Quais são os pontos de acesso de uma fila e qual é a função de cada um deles?
4. Por que uma fila continua sendo uma fila mesmo quando é implementada com estruturas diferentes, como listas, vetores ou listas encadeadas?
5. Explique o que são estado e invariantes em uma fila e cite dois exemplos de invariantes que sempre devem ser respeitados.
6. Qual a diferença entre as operações enqueue, dequeue e front em uma fila, considerando o efeito de cada uma sobre os elementos armazenados?
7. Por que é importante verificar se a fila está vazia antes de executar a operação dequeue?
8. Explique por que, em uma fila, a ordem de chegada dos elementos é fundamental para determinar qual elemento será removido primeiro.
